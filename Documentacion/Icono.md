## Prompt utilizado

Edit target: attached XoloPark dog mark. Create production iOS app icon, square 1024x1024 opaque PNG. Preserve the exact angular black xolo head identity and red negative-space facial details from reference, same orientation. Reframe with complete ears and head, centered with 12% margin around silhouette, crop neck at bottom tastefully. Uniform flat red background matching reference extends edge to edge. No words, letters, borders, circular badge, gradients, shadows, rounded corners, phone mockup. This is an adaptation of existing logo, not a redesign. Output only icon.
